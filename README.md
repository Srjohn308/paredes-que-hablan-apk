# Paredes que Hablan — Android (APK)

Archivo digital y participativo del graffiti y arte urbano de Bogotá.

## Descargar
Ve a [Releases](../../releases/latest) y baja `ParedesQueHablan-v1.0.1.apk`.

## Instalar
1. Abre el archivo descargado en tu celular Android.
2. Si te lo pide, permite "Instalar apps de fuentes desconocidas" para tu navegador.
3. Si Play Protect muestra un aviso, elige "Instalar de todos modos".

Las actualizaciones por esta vía son manuales: descarga el APK nuevo de Releases.
